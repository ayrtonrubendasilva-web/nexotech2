Nuestra conclusión / Our conclusion

Español: Haciendo este proyecto aprendimos a organizar un sitio web completo en varias páginas conectadas entre sí, y a usar HTML, CSS y JavaScript en conjunto para armar funciones reales como un carrito de compras, un buscador y un checkout simulado. También incorporamos vocabulario técnico nuevo en inglés relacionado con el comercio online y la tecnología. La mayor dificultad fue mantener coherente el contenido bilingüe en las 8 páginas, algo que resolvimos revisando cada sección con cuidado y apoyándonos en herramientas de traducción como el Traductor de Google.


English: By doing this project we learned to organize an entire website into several pages connected to each other, and to use HTML, CSS and JavaScript together to put together real functions such as a shopping cart, a search engine and a simulated checkout. We also incorporate new technical vocabulary in English related to online commerce and technology. The biggest difficulty was keeping the bilingual content coherent on the 8 pages, something we solved by reviewing each section carefully and relying on translation tools such as Google Translate.
